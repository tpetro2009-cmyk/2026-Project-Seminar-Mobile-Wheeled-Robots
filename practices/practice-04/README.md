## 3. Запуск проекта

Сборка пакета:

```bash
cd ~/practices_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select webots_amcl_localization
source install/setup.bash
```

Запуск локализации:

```bash
ros2 launch webots_amcl_localization localization.launch.py
```

Для запуска экспериментов используются параметры количества частиц и начальной позы AMCL.

## 4. Методика экспериментов

Проведено шесть экспериментов с различными условиями инициализации AMCL.

Используются два диапазона количества частиц:

- Малое количество: 100–500.
- Большое количество: 1000–3000.

Истинная начальная поза робота: (1.5, 0.5, 1.5708).

Начальные условия AMCL:

- Малая ошибка: (1.68, 0.56, 1.62).
- Большая ошибка: (0.5, 0.5, 0.0).
- Глобальная инициализация: равномерное распределение частиц.

### Критерии сходимости

Локализация считается сошедшейся, если одновременно выполняются условия:

- Ошибка положения меньше 0.15 м.
- Ошибка ориентации меньше 0.15 рад.
- Оба условия выполняются непрерывно в течение 3 секунд.

Время сходимости измеряется от начала эксперимента по симуляционному времени.

## 5. Результаты экспериментов

| № | Инициализация | Количество частиц | Время сходимости |
|---|---|---|---:|
| 1 | Глобальная | 100–500 | 6.56 с |
| 2 | Глобальная | 1000–3000 | 9.12 с |
| 3 | Малая ошибка | 100–500 | 17.86 с |
| 4 | Малая ошибка | 1000–3000 | 6.56 с |
| 5 | Большая ошибка | 100–500 | Не достигнута |
| 6 | Большая ошибка | 1000–3000 | Не достигнута |

### Анализ результатов

1. При глобальной инициализации сходимость была достигнута в обоих экспериментах.
2. При небольшой ошибке начальной позы оба варианта количества частиц обеспечили сходимость.
3. В эксперименте с малой ошибкой и большим количеством частиц время сходимости оказалось меньше.
4. При большой ошибке начальной позы локализация не сошлась ни при малом, ни при большом количестве частиц.

Таким образом, увеличение количества частиц само по себе не гарантирует успешную локализацию при значительной ошибке начальной оценки.

## 6. Сбор и визуализация данных

Для каждого эксперимента сохраняется CSV-файл с временными рядами:

- истинные координаты робота;
- оценка координат AMCL;
- ошибка положения;
- ошибка ориентации.

Для визуализации используются скрипты:

```bash
python3 plot_results.py
python3 plot_comparison.py
```

Для каждого эксперимента строятся три графика:

1. Сравнение траекторий Ground Truth и AMCL.
2. Ошибка положения с порогом 0.15 м.
3. Ошибка ориентации с порогом 0.15 рад.

Дополнительно строится общий график времени сходимости шести экспериментов.
